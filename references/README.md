## Visual Direction

Lovcore should feel like a private AI/business intelligence archive, not a SaaS dashboard.

Keep:

- mymind-like no-folder memory wall
- editorial typography
- large calm search input
- beautiful mixed cards
- private archive mood
- AI/business research references

Avoid:

- social feed behavior
- heavy dashboards
- blue-purple AI gradients
- 3D space metaphors
- gamified interactions
- generic productivity template aesthetics
